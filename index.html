How it works:
• Exclusive = exact elapsed time between the two moments.
• Inclusive = exclusive + 24 hours (counts both the start day and end day, e.g. hotel nights vs. calendar days, age-in-days problems).
• Calendar breakdown (years / months / days) accounts for leap years and varying month lengths.
• If End is before Start, dates are auto-swapped.
• Shareable link: state lives in the URL, e.g. ?start=2020-01-01&end=2026-10-15&startTime=09:30&endTime=17:45 — opening that URL restores the dates/times instantly. Omit end (or leave it empty) and the end date defaults to today.
• Age mode: append &age_calc=true to auto-open the 🎂 age pop-up, e.g. ?start=2002-02-27&end=2026-10-15&startTime=00:00&endTime=00:00&age_calc=true. Age always uses the exclusive count (end date excluded) — the standard way to measure age.
